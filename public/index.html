Application Guide & Documentation

🚀 Quick Start Guide

Paste any target LinkedIn profile URL into the search bar (e.g., https://www.linkedin.com/in/vanity-id/) and click Run Pipeline. The system returns structured JSON including Name, Headline, Location, Bio, Experience, Education, Skills, Certifications, and Profile Images.

🔒 Zero-Cookie Public Mode

By default, standard searches execute via unauthenticated public extraction. This mode transmits zero session cookies, eliminating browser session logout risks.

⚡ In-Memory LRU Caching

Profile payloads are cached in RAM for 1 hour. Repeated requests return in <3ms with the X-Cache: HIT header.

🔑 Rate Limit Tiers & Authentication

Pass the x-api-key header to unlock higher rate limits:

  • Enterprise Tier (x-api-key: tross-enterprise-key): 1,000 requests per 15 mins.
  • Demo Tier (x-api-key: tross-demo-key): 100 requests per 15 mins.
